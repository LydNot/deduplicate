# deduplicate
This script identifies duplicates, generates a deduplicated list, and outputs duplicate frequencies!

The list should be in a format like my 'New Vocab' [list](https://docs.google.com/document/d/11vSxpEnDLOeAo-m05NXvuiFtiYO2grQaHt5R0bWewkY/edit?usp=sharing): new paragraphs for each list item.
